① 批次建立學生帳號

學生登入時輸入「班級＋座號＋密碼」。第一次幫某一班建立帳號時，這個班就會登記在你名下，其他老師看不到、也不能再建同一班。

①-2 匯入全校名單，一次建立帳號

選 CSV 檔（要有「班級」「座號」「姓名」三欄，Excel 存成 CSV 即可）。檔案只在你的瀏覽器裡讀取，只會把勾選班級的資料建成帳號；姓名存在雲端，只有該班老師和管理人看得到。

例：701 班 5 號 → bio70105

② 帳號清單與列印帳號條

清單只顯示「初始密碼」。學生自己改過密碼的，會顯示「已自行修改」。

④ 忘記密碼怎麼辦？

學生忘記密碼：請管理人在 Firebase 主控台刪除該學生帳號（班級-座號@student.bio），再由任課老師用 ① 只重建這一位（例如座號從 5 到 5）。學習進度存在「班級-座號」底下，會保留。

老師忘記密碼：在總入口「老師登入」按「忘記密碼？」，重設信會寄到你的電子郵件。登入後也可以按「🔑 改密碼」。

⑤ 管理人專區

老師註冊申請

老師在總入口按「📝 老師註冊」送出申請。按「✔ 通過」後，系統會自動寄一封「設定密碼」的信給他。

設定老師任教班級

先選老師，再勾他任教的班級，按「儲存」。一個班只能有一位負責老師；勾了別人的班，會改成這位老師負責。班級還沒建帳號也可以先設定，之後由該老師在 ① 建立。

班級與負責老師

可以把班級改指派給其他老師（例如換任課老師）。「未指派」的班級只有管理人看得到。

老師名單

老師要先登入老師工具一次，才會出現在這裡。

➕ 怎麼新增一位老師？

最簡單：請老師到總入口 → 老師登入 →「📝 老師註冊」送出申請，你在上面「老師註冊申請」按「✔ 通過」即可。

也可以在 Firebase 主控台手動新增：

  1. Firebase 主控台 → Authentication → 使用者 → 新增使用者（填老師的電子郵件和暫時密碼）。
  2. 複製他的「使用者 UID」。
  3. Realtime Database → 資料 → teachers → ＋ → 索引鍵貼 UID，值 true。
  4. 請老師到總入口用「老師登入」，再打開老師工具一次，並填好「您的稱呼」。
